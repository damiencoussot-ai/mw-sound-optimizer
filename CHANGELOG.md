# Changelog

Format : [Keep a Changelog](https://keepachangelog.com/fr/1.1.0/). Versions : [SemVer](https://semver.org/lang/fr/).

## [3.0.0]

### Ajouté
- Interface « Tactical Audio HUD » : courbe d'égaliseur interactive, spectre en direct.
- Mode simple (4 profils, force de l'effet) et mode expert.
- Outils : largeur stéréo, coupe-explosions, balance, inversion G/D, A/B, sons de test, mini HUD.
- Auto Warzone (détection du jeu), raccourcis `Ctrl+Alt+F9` / `F10`, démarrage avec Windows.
- Voicemeeter : détection de l'édition, VU-mètre, commandes, EQ natif Banana / Potato.
- Choix de la sortie ciblée, relue automatiquement quand la liste d'Equalizer APO change.
- Sortie Windows par défaut : lecture seule, modification optionnelle (« Modifier Windows : OUI ») avec « Restaurer ».
- Logo et icône.

### Connu
- Mode Voicemeeter natif : type de filtre et conversion du Q non vérifiés sur Banana / Potato.
- Rendu audio de la largeur stéréo et du coupe-explosions à valider à l'oreille.
